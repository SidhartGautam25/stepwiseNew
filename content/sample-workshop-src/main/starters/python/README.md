# Build your own HTTP Server (Python Starter)

This is the official Python starter project for the **Build your own HTTP Server** workshop on Handrail.

## Running Locally

Run your server:
```bash
python3 server.py
```

Verify it responds on port 4221:
```bash
curl -v http://localhost:4221
```

## Submitting Work
Commit your changes and push to GitHub:
```bash
git add .
git commit -m "Implement TCP socket binding"
git push origin main
```
