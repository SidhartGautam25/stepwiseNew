# Theory: Mounting the Virtual DOM (Beginner)

Mounting is the process of translating virtual DOM objects into actual browser DOM elements.
Browsers display UI through the live DOM tree. When our render function runs:
1. It queries the DOM or receives a root container (like `<div id="root"></div>`).
2. It constructs the required DOM elements in memory.
3. It attaches them into the document hierarchy so the browser engine can paint them onto your screen.
