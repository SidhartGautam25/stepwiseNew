# Theory: The Call-Stack Problem (Intermediate)

Recursive rendering traverses the entire virtual DOM tree using JavaScript function calls on the execution call stack.
If a component tree contains 10,000 nodes, the JavaScript engine will stay locked in the render function until all 10,000 nodes are created.
During this time:
- The browser cannot respond to user clicks.
- Animations drop frames.
- Typing in input fields stutters.
This bottleneck inspired the creation of React Fiber, which we will build in Chapter 2.
