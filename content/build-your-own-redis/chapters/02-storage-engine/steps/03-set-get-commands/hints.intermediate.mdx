### Hints (Intermediate)

- For `SET`:
  ```go
  mu.Lock()
  store[key] = val
  mu.Unlock()
  conn.Write([]byte("+OK\r\n"))
  ```
- For `GET`:
  ```go
  mu.RLock()
  val, ok := store[key]
  mu.RUnlock()
  if !ok {
    conn.Write([]byte("$-1\r\n"))
  } else {
    conn.Write([]byte(fmt.Sprintf("$%d\r\n%s\r\n", len(val), val)))
  }
  ```
