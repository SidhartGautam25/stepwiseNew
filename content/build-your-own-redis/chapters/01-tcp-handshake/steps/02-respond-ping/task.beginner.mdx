### Your Task (Beginner)

Now that your server is listening, let's make it respond to the most fundamental command in Redis: `PING`.

1. When a client connects, read the incoming bytes.
2. In Redis, `PING` arrives encoded as RESP: `*1\r\n$4\r\nPING\r\n`.
3. When you detect a `PING` command, reply with the simple string `+PONG\r\n`.
4. Make sure your server keeps reading from the client in a loop so it can handle repeated `PING` commands.
5. Push to GitHub to test your implementation.
