### Your Task (Beginner)

Welcome to your first step! In this step, you will start by creating a basic TCP server that listens for incoming network connections.

1. Open your project in your local code editor.
2. Locate the main server entry point:
   - For Go: `app/main.go`
   - For Python: `app/main.py`
3. Bind your server socket to address `0.0.0.0` or `127.0.0.1` on port `6379`.
4. Accept incoming TCP connections in a loop so the server stays alive.
5. Commit and push your changes to GitHub to trigger automated verification.
