# Task: Lockfile & Bin Linking (Beginner)

Your program should respond to the `install` command:
```bash
your_pm install
```

### Instructions
1. Read `package.json` from the current working directory.
2. Resolve all dependencies and extract them into `node_modules/`.
3. Generate a `handrail.lock` lockfile with the resolved tree:
   ```yaml
   lockfileVersion: 1
   packages:
     chalk@5.3.0:
       version: "5.3.0"
       resolution: "https://registry.npmjs.org/chalk/-/chalk-5.3.0.tgz"
       integrity: "sha512-..."
   ```
4. For each installed package, check its `package.json` for a `"bin"` field.
   Create an executable link or script inside `node_modules/.bin/<name>` pointing to that binary file.
