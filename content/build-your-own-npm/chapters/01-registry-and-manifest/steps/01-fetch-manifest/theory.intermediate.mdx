# Theory: Semantic Versioning (SemVer) (Intermediate)

SemVer follows the format `MAJOR.MINOR.PATCH`:
- `MAJOR`: Breaking changes that break existing code.
- `MINOR`: New backwards-compatible features.
- `PATCH`: Backwards-compatible bug fixes.

Version range operators:
- `^1.2.3`: Allows updates that do not increment the leftmost non-zero digit (`>= 1.2.3 < 2.0.0`).
- `~1.2.3`: Allows patch updates only (`>= 1.2.3 < 1.3.0`).
- `*` or `latest`: Selects highest stable version available.
